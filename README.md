# «Хочу Пиццы!» — Сайт-лендинг ремесленной пиццерии

Современный, быстрый и отзывчивый веб-сайт для ресторана ремесленной пиццы **«Хочу Пиццы!» (Pizzeria & Forno a Legna)**.

Сайт разработан в соответствии со стандартами дизайн-системы **shadcn/ui**, правилами чистого интерфейса (Anti-AI-Slop Craft Floor) и гайдлайнами `frontend-design`.

---

## 🍕 Особенности проекта

1. **Гастрономическая аутентичность и бренд-дизайн**:
   - Палитра теплых итальянских тонов: основа муки и закваски (`#FBF8F3`), насыщенный оттенок томатов Сан-Марцано (`#D13518`), глубокий древесный уголь печи (`#171311`).
   - Итальянская типографика: заголовочный антиквенный шрифт `Playfair Display`, чистый системный `Plus Jakarta Sans`, моноширинный `JetBrains Mono` для веса, калорийности и цен (`font-mono tabular-nums`).
   - Светлая и темная темы (переключение токенов через HSL CSS-переменные).

2. **Интерактивное меню пиццерии**:
   - Категории: Неаполитанская, Римская на лопате (Scrocchiarella), Спешлы шефа, Закуски & Салаты, Десерты, Напитки.
   - Быстрые фильтры по диете: «Все», «Хиты гостей», «Вегетарианские», «Острые».
   - Переключатель диаметра: 28 см (классика) / 33 см (большая) с моментальным пересчетом веса и стоимости.

3. **Интерактивный конструктор пиццы (Pizza Customizer)**:
   - Выбор диаметра (28 / 33 см).
   - Выбор бортика: традиционный неаполитанский леопардовый припёк или сырный бортик моцарелла Fior di Latte.
   - Добавление топпингов (прошутто, страчателла, горгонзола, трюфель, базилик, пепперони).
   - Подсчет веса, стоимости и передача особых пожеланий шефу.

4. **Выдвижная корзина и оформление заказа (Cart & Checkout)**:
   - Индикатор бесплатной доставки с динамическим прогресс-баром (бесплатно от 1 200 ₽).
   - Применение промокодов (`ХОЧУ15`, `ХОЧУ20`).
   - Переключение Доставка / Самовывоз со скидкой 10%.
   - Выбор способа оплаты: СБП онлайн, Картой курьеру, Наличными.
   - Генерация номера заказа и расчет времени доставки.

5. **Ремесленная история и философия печи**:
   - 4 столпа качества: 36 часов холодной ферментации теста Lievito Madre, помпейская печь Marana Forni на 450°C, мука Caputo Tipo 00, томаты San Marzano D.O.P.
   - Сравнительная таблица ферментации (быстрое тесто vs 36 часов).

6. **Интерактивная проверка адреса и зон доставки**:
   - Ввод улицы для мгновенного определения зеленой (25-35 мин) или желтой (35-45 мин) зоны.

7. **Онлайн-бронирование столиков**:
   - Выбор количества персон (1–8+), даты, времени, зоны зала («У печи», «Тихий зал», «Терраса»).
   - Мгновенное подтверждение и выдача номера брони.

8. **Отзывы гостей и интерактивный FAQ-аккордеон**.

## 🚀 Запуск проекта

### Режим разработки (Dev Server):
```bash
npm run dev
```
Сайт откроется локально по адресу `http://localhost:5173`.

### Сборка для продакшна (Production Build):
```bash
npm run build
```

### Предпросмотр собранной версии:
```bash
npm run preview
```
